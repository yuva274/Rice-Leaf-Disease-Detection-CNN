# Rice Leaf Disease Detection Using CNN

## Project Overview
This project uses Deep Learning and Convolutional Neural Networks (CNN) to identify diseases in rice leaves from images.

## Objectives
- Analyze rice leaf images.
- Preprocess and augment image data.
- Build and train a CNN-based classification model.
- Evaluate model performance.

## Technologies Used
- Python
- TensorFlow
- Keras
- NumPy
- Pandas
- Matplotlib
- Jupyter Notebook

## Methodology
1. Image dataset collection
2. Image preprocessing
3. Data augmentation
4. CNN model development
5. Model training and evaluation

## Models
- CNN
- MobileNet-based model

## Applications
This project demonstrates how deep learning can support automated rice leaf disease identification.
